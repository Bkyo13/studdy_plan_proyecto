# Capturas

Pon aquí las capturas con estos nombres exactos (el README ya las busca así):

| Archivo | Qué capturar |
|---|---|
| `inicio.png` | Inicio del estudiante con nivel, buscador y 2–3 tareas |
| `detalle.png` | Detalle de una tarea con pasos (algunos palomeados) |
| `calendario.png` | Calendario con puntitos y una tarea abajo |
| `logros.png` | Pestaña Logros con alguno desbloqueado |
| `asistente.png` | Asistente IA respondiendo |
| `tutor.png` | Panel del tutor con el resumen del estudiante |
| `admin.png` | Admin: lista de materias |
| `login.png` | Pantalla de inicio de sesión |

Usa el emulador o tu teléfono, en vertical. Si las sacas en el emulador, usa el botón de cámara de la barra lateral.
